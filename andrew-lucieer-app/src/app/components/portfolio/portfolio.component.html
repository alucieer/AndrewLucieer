Process / Three fresh attempts

How I refined the skill

This component became a test case for improving the skill itself. For each attempt, I reverted the component to its original state and started a fresh Claude Code agent with no shared context, so each run tested only the skill.

  1. Attempt 1: The skill couldn't fix the close button's contrast, because the low contrast came from opacity, not a raw hex color. I updated the skill's contrast guidance to handle that case.
  2. Attempt 2: The contrast fix worked, but the skill left off the attr. prefix on an aria-label binding. The label rendered the variable names instead of their values. That kind of bug passes a quick glance and fails a screen reader user. I updated the skill's verification file to check for that specific mistake.
  3. Attempt 3: Starting from the same original component, a fresh agent fixed every WAVE-reported error in one pass, with no manual edits.

Each failure became a permanent check in the skill, so the same mistake won't happen on the next component. The skill handles what automated checkers can find. It doesn't add keyboard reordering for the drag handles, which WAVE can't detect, so that still needs a human.
